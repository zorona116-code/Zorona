# ZORONA Restaurant & Cafe

ZORONA website source repository. The first bootstrap commit uploads the project archive; GitHub Actions expands it, runs CI on Node.js 24, and commits the source tree to `main`. The source tree includes Dockerfiles for both public web/API and admin services, regression tests, documentation, and dependency automation.

Production deploys are not considered complete until the hosting provider reports success and health/booking/admin checks pass. See `docs/DEPLOYMENT.md` after bootstrap.
